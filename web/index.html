PDF evidence search

Upload a PDF, ask a question, and get an answer that cites the exact table cells it came from, with their page and bounding box. The math is done in code, not by the model.

What happens

    
    
      
  1. Client (this page) asks the API for an upload URL.
    2. 
      
  2. API service saves a document row in Postgres (status queued) and returns a signed URL good for 10 minutes.
    3. 
      
  3. S3 stand-in: the client PUTs the PDF to that URL, which saves it to storage.
    4. 
      
  4. Queue: the doc ID goes on the queue.
    5. 
      
  5. OCR worker reads each page (Tesseract for scanned pages) and writes one row per page: its HTML, where every cell has an id, a value and a box, and its text.
    6. 
      
  6. DLQ: after 3 failed tries the document is marked failed and its ID goes on a dead-letter queue.
    7. 
      
  7. Postgres holds two tables, documents and pages, with a full-text index on the page text.
    8. 
      
  8. Query service finds the top 3 pages with Postgres full-text search.
    9. 
      
  9. LLM (Claude Haiku 5.5) names the cells and a formula; Python checks every cell exists and does the math.
    10.
